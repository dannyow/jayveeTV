# firmware/platform

Everything that makes this a television instead of a screen running a program. A channel
never touches this layer directly; see `firmware/channels/`. The why, the data flow and
the timing budget are in `docs/ARCHITECTURE.md`; this file is just a map.

| file | module |
|---|---|
| `set.cpp` / `set.h` | the set's state machine: power, station switching, tuner/CRT composition, keys, orientation, knock, serial dev commands. `main.cpp` is just `setup()`/`loop()` calling into this. |
| `channel.h` | the `Channel`/`ChannelInfo` contract every channel implements; see `docs/CHANNELS.md` |
| `tuner.cpp` / `tuner.h` | reception state: locked / losing / lost / tuning, detune, knock reaction |
| `crt.cpp` / `crt.h` | the picture tube: warm-up bloom, power-off collapse, afterglow |
| `glitch.cpp` / `glitch.h` | analog degradation applied at blit time: roll, bend, jitter, snow, hum bar, scanlines, chroma drain |
| `sound.cpp` / `sound.h` | the `Sound` struct a channel fills in, mixed over the set's own hiss/hum/whistle bed |
| `input.cpp` / `input.h` | one event queue for keys, touch, serial and phones; pure C, also built by `tools/hostrender` |
| `arena.cpp` / `arena.h` | one static 64 KB block for buffers that never coexist (`arenaClaim()`/`arenaRelease()`) |
| `remotecard.cpp` / `remotecard.h` | the REMOTE card overlay: Wi-Fi QR or controller-page QR, client count |
| `board.h` | pin map for the Waveshare ESP32-C6-Touch-AMOLED-2.16 |
| `qrcodegen.c` / `qrcodegen.h` | vendored QR code generator (Project Nayuki, MIT; see `THIRD_PARTY.md`) |
| `font5x7.h` | the bitmap font used by the REMOTE card and the host contact sheets |

## `hw/`: hardware drivers

| file | driver |
|---|---|
| `display.cpp` / `.h` | SH8601 AMOLED over QSPI, slice-streamed (no full framebuffer fits in SRAM) |
| `audio.cpp` / `.h` | ES8311 codec over I2S, continuous synth task |
| `imu.cpp` / `.h` | QMI8658 accelerometer/tap detector (orientation, knock) |
| `power.cpp` / `.h` | AXP2101 PMU: must init before the display; panel rails and reset come from it |
| `rtc.cpp` / `.h` | PCF85063 real-time clock, fails soft |
| `net.cpp` / `.h` | Wi-Fi AP/STA, NVS credentials; see `docs/NETWORK.md` |
| `webctl.cpp` / `.h` | the phone remote's HTTP server and WebSocket; see `docs/REMOTE.md` |
| `webctl_page.h` | generated by `tools/remote/build_page.py`; do not edit |
| `i2c_lock.h` | one recursive mutex around the shared I2C bus |
