# docs

The four documents behind this project. Suggested order:

1. [`ARCHITECTURE.md`](ARCHITECTURE.md): the platform/channel split, the data flow, the
   timing budget, the build profiles. Start here.
2. [`CHANNELS.md`](CHANNELS.md): how to write a channel: the `Channel` contract, the
   picture and sound rules, the host-side check, definition of done.
3. [`REMOTE.md`](REMOTE.md): the phone remote: shell vs. panel, the panel block types a
   channel can declare, the HTTP/WebSocket protocol.
4. [`NETWORK.md`](NETWORK.md): first boot, joining home Wi-Fi, the physical/remote
   "forget network" reset, and what's stored where.
